# Tapestry Deconvolution Model Architecture

## Problem

Estimate the latent composition vector **p** = (p₁, ..., p₁₃) over 13 cell types from cfDNA methylation data. We observe ~3,000 marker regions, each with an unmethylated read count (u), methylated read count (m), and total coverage (c = u + m).

## Statistical Framing

The observed data at each marker is generated by a noisy compositional process:

1. The cfDNA mixture has latent proportions **p** = (p₁, ..., p₁₃).
2. At each marker j, the expected unmethylated probability is a linear combination of the reference cell-type methylation probabilities (estimated from reference PAT files), weighted by **p**: q_j = Σ_k p_k × atlas[j, k], under the standard linear mixing assumption for marker-level unmethylated probabilities.
3. Conditional on coverage, observed counts are generated stochastically from the marker-specific unmethylated probability.
4. We observe only the resulting counts (u, m) — noisy realisations of the underlying mixture.

NNLS ignores the observation model: it fits observed fractions directly, without modelling the coverage-dependent uncertainty in those fractions. At the marker-level coverages typical of clinical cfDNA (5–20 reads), the observed fraction can deviate substantially from the expected fraction. NNLS also does not naturally promote sparse solutions — in real samples, where most tissue types are absent, it often assigns small non-zero proportions to many classes in order to reduce residual error.

**The neural network is an amortised inference model**: the encoder provides amortised inference for the latent mixture proportions, while the decoder ties these predictions back to the atlas-defined observation model through a count likelihood. Given noisy count observations across thousands of markers, it learns to invert this noisy generative process.

**Core limitation**: this is atlas-based inference. If the true mixture contains a cell type outside the 13-class atlas, the model is forced to project it onto known classes, which can produce biologically plausible false positives. This is not merely a risk — it is a fundamental property of the approach that must be stress-tested.

## Model Overview

A two-level transformer that takes raw marker count observations and outputs sparse cell-type proportions.

```text
Per-marker embedding (counts + coverage → feature_dim)
    ↓
Level 1: Within-cell-type transformer (markers attend to sibling markers)
    ↓
Pooling → one summary vector per cell type
    ↓
Level 2: Cross-cell-type transformer (cell type summaries attend to each other)
    ↓
Proportion head → nonneg masses → normalise → (p₁, ..., p₁₃)
    +
Detection head → per-cell-type presence probabilities (auxiliary)
    +
Decoder → marker-level expected counts → beta-binomial NLL (auxiliary)
```

## Components

### 1. Per-Marker Embedding

Each marker is embedded using features derived from the observed counts and coverage:

- **u / max(c, 1)**: observed U-fraction
- **log1p(u)**: unmethylated count on log scale
- **log1p(m)**: methylated count on log scale
- **log1p(c)**: total coverage on log scale

These four channels are concatenated and projected to feature_dim. Using raw counts (not just the fraction) preserves the discrete low-count structure: 0/1, 1/2, and 2/4 all have different uncertainty profiles even when fractions are similar.

Each marker also receives a **marker identity embedding** (learned, fixed per marker position) so the model can learn marker-specific reliability and behaviour.

Markers with zero coverage are masked throughout and never contribute to attention or aggregation.

### 2. Level 1: Within-Cell-Type Transformer

Each cell type's ~250 markers attend to each other through standard transformer encoder layers. This is where cross-marker reasoning happens: a single marker showing elevated signal at 3 reads could be noise, but if 15 other markers for the same cell type also show elevated signal at low coverage, the evidence accumulates coherently. The transformer learns to distinguish **coherent weak evidence across many markers** from **isolated stochastic outliers**.

Marker identity embeddings allow the model to learn which markers within a cell type are more or less reliable.

Cost: 13 × O(250²) per layer — roughly 12× cheaper than full 3,000² attention.

### 3. Aggregation

After Level 1, each cell type's marker representations are pooled into a single summary vector. **Masked mean pooling** (average over non-masked markers) is the baseline. Attention-weighted pooling is an option but risks circular logic — "clearer signal gets more weight" requires the model to already know what clear signal looks like. Benchmark attention pooling against masked mean before committing.

This produces a (13, feature_dim) tensor — one summary per cell type.

### 4. Level 2: Cross-Cell-Type Transformer

Because marker panels are only partially cell-type-specific, the model needs a global stage that resolves conflicting evidence across cell types after within-type evidence has been accumulated. The 13 cell-type summaries attend to each other through 1–2 shallow transformer layers:

- **Competition**: overlapping marker information between cell types needs to be arbitrated.
- **Relative confidence calibration**: a cell type with a weak, uncertain summary vector, surrounded by high-confidence summaries that already explain the data, should receive little or no mass.

Keep this shallow. Heavy cross-cell-type interaction risks learning cohort-specific composition priors rather than reasoning from marker evidence.

### 5. Proportion Head

Each cell type's refined vector passes through a small MLP that outputs a **nonnegative unnormalised mass**:

```text
a_k = softplus(score_k)
```

Proportions are obtained by normalisation:

```text
p_k = a_k / Σ_j a_j
```

Sparsity is encouraged through regularisation on the nonnegative masses (for example L1 or entropy penalties), with sparse simplex mappings such as sparsemax or entmax tested separately as alternative output transforms. No hard gate multiplied into the mixture path during training — this avoids the optimisation pathologies of competing shrinkage mechanisms.

### 6. Detection Head (Auxiliary)

A separate head predicts per-cell-type presence probabilities, supervised by whether the true proportion exceeds a threshold (e.g. 0.1%). This separates abundance estimation from detection, reducing interference between the two objectives. The detection head is used **at inference only** for reporting presence/absence decisions.

### 7. Observation Model Decoder (Training)

A decoder maps predicted proportions to expected marker-level unmethylated probabilities using the known reference atlas:

```text
For each marker j:
  q_j = Σ_k p_k × atlas[j, k]     (expected U-probability; atlas is fixed during training)
  NLL_j = -log BetaBinom(u_j | c_j, q_j, φ), where q_j is the mean unmethylated
          probability implied by the predicted mixture and φ controls overdispersion
```

Training uses a beta-binomial likelihood as the default to model overdispersion across samples and assay variability, with plain binomial as the simpler baseline for ablation.

This is more principled than a generic reconstruction loss because:

- It naturally weights by coverage (high-coverage markers contribute more likelihood)
- It properly models the discrete sampling process
- It links predicted proportions directly to observed data through the known generative model
- The beta-binomial extension handles reference variability across donors and assays

## Training

- **Data**: synthetic mixtures generated from real reference PAT files across realistic sample-level sequencing depths, producing marker-level coverages spanning the low-read regime typical of cfDNA.
- **Primary loss**: proportion loss on known synthetic mixtures (MSE or Huber, with concentration-dependent weighting — low concentrations get higher weight).
- **Auxiliary losses**: beta-binomial NLL through decoder, detection BCE, sparsity regularisation.
- **Ablation**: optionally provide per-sample NNLS estimates as an additional input feature. This is not part of the core architecture — the baseline model stands on its own — but is worth testing as a residual-correction variant.
- **Synthetic data realism is critical**: sample whole reference profiles (not just mean values), preserve correlated marker structure within cell types, simulate realistic read depth distributions, include batch noise and missingness.

## Uncertainty

The current model outputs point estimates of composition. For clinical deployment, particularly for rare-cell detection at 0.1–0.5% in low-coverage samples, point estimates alone are insufficient. Planned extensions include calibrated uncertainty estimation via ensemble variance, quantile heads, or distributional output parameterisations.

## Evaluation

- Per-cell-type MAE, R², and Pearson correlation
- **Log-space metrics**: R², slope, and intercept on log10(predicted + ε) vs log10(true + ε) — critical for verifying linearity across orders of magnitude, especially in the 0.1–5% range where clinical decisions are made
- Error as a function of true abundance (range-stratified: ultra-low / low / medium / high)
- Presence/absence precision-recall at low abundance
- Compositional metrics: Aitchison distance, compositional L1
- Robustness by coverage tier
- Structured dilution series for OAC and T-cells
- Real cfDNA (AB/CD cohorts): healthy controls should show ~0% OAC

## Known Risks

| Risk | Mitigation |
| ---- | ---------- |
| Out-of-reference cell types | Stress test with held-out cell types; consider an "other/unknown" mass term; monitor false-positive patterns in healthy controls |
| Reference uncertainty (marker signatures vary across donors, disease, assays) | Beta-binomial decoder handles overdispersion; LOO evaluation tests generalisation |
| Compositional dominance (one type at 60% makes rare types hard to identify) | Concentration-weighted loss; dilution series evaluation; uncertainty extensions |
| Marker assignment rigidity (some markers carry information about multiple types) | Acknowledged trade-off for efficiency; Level 2 partially compensates; can be revisited if marker-type leakage is observed |
| Simulator mismatch (model learns the simulator, not biology) | Use real PAT file mixing, realistic coverage distributions, include contamination/noise |

## Parameters (Estimated)

- feature_dim: 128
- Level 1: 2–3 layers, 4 heads, per cell type (~250 markers)
- Level 2: 1–2 layers, 4 heads, 13 tokens
- Proportion head: MLP (128 → 64 → 1) × 13 cell types, softplus output
- Detection head: MLP (128 → 1) × 13 cell types, sigmoid output
- Total: ~2–4M parameters
- Training: feasible on a single GPU, batch size 32–64
