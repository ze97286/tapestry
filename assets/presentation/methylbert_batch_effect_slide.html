Suspicious batch effect in the MethylBERT read classifier

The classifier separates most healthy controls from tumour tissue, but four high-coverage AB controls form a tumour-like control domain.

Main interpretation

This looks like domain shift, not ordinary read-level noise.

Why this matters

The clinical MLE would treat high read-level tumour probability as tumour fraction. If a control batch is already tumour-like, downstream purity estimates can inherit a batch-confounded false-positive signal.

Conclusion for this route

The classifier has signal, but it is not clinically trustworthy yet. The next useful test is not more threshold tuning; it is batch-aware training/evaluation or excluding the shifted AB control domain from claims of specificity.
